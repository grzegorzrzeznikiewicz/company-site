# Gama SEO

`gama-software/gama-seo` is the first-party SEO boundary for the Gama Software
WordPress site. It generates title, description, canonical, Open Graph,
Schema.org, environment-aware robots directives and the legacy sitemap redirect.

It has no paid dependency and makes no external network requests while rendering.
WordPress Core remains the XML sitemap provider at `/wp-sitemap.xml`.
